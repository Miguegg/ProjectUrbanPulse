# Contribution guide

## Workflow
1. Create a branch from `main`.
2. Make the changes.
3. Run tests.
4. Open a Pull Request.
5. Wait for review.

## Commit convention
We use Conventional Commits:
- `feat`: new functionality
- `fix`: bug fix
- `docs`: documentation
- `test`: tests
- `refactor`: refactoring
- `chore`: internal tasks

Example:

```bash
git commit -m "feat: add task creation endpoint"
```
